The problem

AI research tools optimize for the deliverable. The PDF arrives, but the understanding that should come with it gets skipped. The real value is the trail of thinking, and today that trail disappears. Thesis 1

The canvas is the hero

Every conversation gets its own canvas. Chat floats on top as the command channel, while agents place sources, notes, questions and live cards on the board. Any card can open its own thread. Harness 1

The board is the research. The PDF is just a view of it.

Cards are plugins

A card plugin brings its own rendering, data source, agent tools and a text description the agent can read. That's how a trader gets live tickers and a UI researcher gets generated design frames on the same canvas. Card plugins 4

Still open

Which user comes first, how to keep boards from cluttering, and where existing tools stop. These stay pinned on the board until the research answers them. Open questions 3
